**TripGo** ("Travel smarter. Explore further.") is a modern, intuitive mobile travel booking app concept designed to streamline destination discovery, hotel selection, and booking management into a seamless user experience.

Developed as **Task 4** during my **CodeAlpha Internship**.

---

## 📱 User Interface & Prototype Flows

The app prototype features an end-to-end booking flow:

1. **Splash & Onboarding:** Welcoming user entry with compelling call-to-actions ("Let's Explore" & "Discover your next adventure").
2. **Home Screen:** Personalized dashboard displaying destination search bar, popular destinations (Dubai, Istanbul, Hunza), and recommended stays.
3. **Search & Exploration:** Search screen featuring recent searches and popular location tags.
4. **Hotel Details & Amenities:** Detailed view showcasing property information, ratings, pricing ($120/night), and amenities (Free Wi-Fi, Swimming Pool, Breakfast, Parking).
5. **Checkout & Summary:** Date picker (Check-in/Check-out), guest selection, room selection, and price breakdown (Room + Taxes).
6. **Payment & Confirmation:** Secure multi-method payment interface (Credit/Debit Card, PayPal, Apple Pay) leading to instant booking confirmation with unique Booking IDs (e.g., `TG-28491`).

---

## ✨ Core Features & Highlights

- **User-Centric Design:** Clean, modern, high-contrast visual design optimized for mobile viewports.
- **Interactive Figma Prototype:** Full user journey prototyping from initial onboarding to completed payment.
- **Structured Architecture:** 9 core screens including Splash, Onboarding, Home, Search, Destination Results, Hotel Details, Booking Details, Payment, and Booking Confirmed.
