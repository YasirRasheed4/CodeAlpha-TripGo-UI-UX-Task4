# ✈️ TripGo — Mobile Travel & Hotel Booking UI/UX

A modern mobile travel and hotel booking app prototype designed in **Figma** as part of the **CodeAlpha UI/UX Design Internship — Task 4**.

TripGo is designed to make travel planning simpler through a clean interface, structured hotel discovery, transparent booking details, and a straightforward booking flow.

---

## 📌 Project Overview

**TripGo — Travel smarter. Explore further.**

TripGo is a mobile travel-booking UI/UX concept that allows users to:

* Explore travel destinations
* Search for hotels and stays
* View hotel details and amenities
* Review booking information
* View a structured price breakdown
* Select a payment method
* Complete a simulated booking flow
* Receive a booking confirmation with a booking ID

This project focuses on **user experience, visual hierarchy, navigation, and interaction design** rather than real-world booking or payment functionality.

## 📱 Screen Flow

The prototype contains a complete 9-screen booking journey:

```text
01. Splash
      ↓
02. Onboarding
      ↓
03. Home
      ↓
04. Search
      ↓
05. Search Results
      ↓
06. Hotel Details
      ↓
07. Booking Details
      ↓
08. Payment
      ↓
09. Booking Confirmation
```

---

## 🖥️ Key Screens

### 1. Splash & Onboarding

Introduces the TripGo brand and provides a clear entry point into the application.

### 2. Home

Provides destination search, popular destinations, and recommended stays.

Example destinations include:

* Dubai
* Istanbul
* Hunza

### 3. Search & Results

Users can search for destinations and browse available stays with filtering and sorting options.

### 4. Hotel Details

Displays important hotel information such as:

* Hotel name
* Location
* Rating
* Price per night
* Description
* Amenities
* Reservation action

### 5. Booking Details

Allows users to review their selected:

* Check-in date
* Check-out date
* Number of guests
* Room type
* Price summary

### 6. Payment

Provides a payment interface with options such as:

* Credit/Debit Card
* PayPal
* Apple Pay

### 7. Booking Confirmation

Displays a confirmation state with a booking reference such as:

`TG-28491`

---

## 🧭 UX Design Principles

### Visual Hierarchy

Important information such as hotel names, ratings, prices, and booking totals is given visual priority.

### Simplified Navigation

The user moves through a clear and structured journey from destination discovery to booking confirmation.

### Transparency

Booking information and price components are presented in an organized format to make the final cost easier to understand.

### Progressive Disclosure

Information is presented step-by-step instead of displaying the entire booking process on a single screen.

### Consistent Interaction

Buttons, selections, cards, and information sections follow a consistent visual and interaction pattern throughout the prototype.

They demonstrate the intended user experience and interaction flow but **do not process real payments or create real hotel reservations**.
